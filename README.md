# kpatel026.github.io

Personal academic website for Kushal Patel, served by GitHub Pages at https://kpatel026.github.io/.

Plain HTML and CSS, no build step.

- `index.html` – all page content
- `style.css` – styling (light and dark mode)
- `files/` – CV and paper PDFs
- `images/` – paper figure and (optional) `profile.jpg` headshot

## Common updates

- **New CV:** replace `files/Patel_CV.pdf` with the new file, keeping the same name.
- **New paper draft:** replace `files/Patel_FX_Borrowing_Monetary_Policy.pdf`.
- **Headshot:** add `images/profile.jpg` (portrait, roughly 4:5). It appears next to the intro automatically; with no file there, the layout simply omits it.
- **New paper:** copy an entry in the Research section of `index.html`.
